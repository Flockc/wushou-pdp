# 五兽之镜 · PDP 行为风格测评

一套用动物意象讲行为风格的自评工具。15 道情境题，5 种类型，3 分钟做完，拿到一张可解释、可分享的行为风格画像。

1024 造物挑战参赛作品的网页版：同一套题库、同一套判定、同一组配色，一个不需要打开游戏就能体验的载体。

- **在线体验**：<https://flockc.github.io/wushou-pdp/>
- **技术栈**：原生 HTML / CSS / JavaScript。无构建步骤、无框架、无第三方库、无外部图片与字体
- **数据**：15 题全在浏览器本地计算，作答内容不上传任何服务器

---

## 一、怎么跑起来

**方式 A（最快）**：双击 `index.html`，用 Chrome / Edge / Firefox 打开，`file://` 下功能完整。

> 注：访问计数需要联网请求第三方服务，`file://` 下同样可用；断网时会自动退回本机统计，不影响其他功能。

**方式 B（本地服务）**

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

**方式 C（静态托管）**：整个目录丢给任意静态托管即可。页面用 hash 路由（`#/test` 这类），**不需要服务端 rewrite 规则**。

## 二、目录结构

```

├─ assets/

│  ├─ data.js          唯一数据源：15 题题库、五型文案、判定参数
```

题库与判定参数都集中在 `assets/data.js`，改题只动这一个文件。

## 三、页面结构

三个视图，靠 hash 路由切换，切换时同步标题与导航高亮。

| 视图 | 路由 | 内容 |

## 四、数据与判定

- **15 题 × 4 选项**，每题四个选项恰好各给 T / P / K / O 中一个维度 +1，答完四项之和恒为 15。
- **作答时不显示维度**，维度信息只在结果页的「答题回顾」中公开，避免照着答案选。
- **判定顺序**：先看 `max - min <= 2` → 判为变色龙型（C）；否则取最高分维度；最高分并列时按 `T > P > K > O` 取先者。
- **可调参数**集中在 `assets/data.js` 的 `CONFIG`：题量、选项数、极差阈值、并列优先级。

五型：老虎（支配）、孔雀（表达）、考拉（耐心）、猫头鹰（精确）、变色龙（整合）。

结果页同时给出：类型与关键词、四维雷达图、四条得分条、判定说明（含极差与阈值）、整体印象 / 核心优势 / 注意盲区 / 发展建议 / 协作提示、逐题回顾、分享卡与文字结果复制。

## 五、交互与状态

| 能力 | 实现 |
|---|---|
| 键盘作答 | `1`–`4` 选择，`←` 回上一题，`Enter` / `Space` 在开始屏进入答题 |
| 鼠标 / 触屏 | 整块选项可点，无悬停依赖；移动端全屏抽屉菜单 |
| 断点续答 | 每次作答写入 `localStorage`（`wushou.pdp.v1`），刷新后可「继续上次」；完成后入口变为「查看上次结果」 |
| 回看与改答 | 「上一题」会撤回该题得分与选择，重新作答不会重复计分 |
| 结果分享 | Canvas 现场绘制 1080×1440 分享卡并下载 PNG |
| 结果复制 | 一键复制纯文本结果（类型、四维得分、极差、优势 / 盲区 / 建议） |
| 动效降级 | 尊重 `prefers-reduced-motion`；无 JS 时内容仍可阅读 |

## 六、访问统计

页脚右侧有一个累计访问计数。口径与实现都写在代码注释里，这里说清楚它**不是**什么：

- **不是**用户画像，**不采集**任何作答内容、设备指纹或行为轨迹。
- 计数来自第三方服务 [hitscounter.dev](https://hitscounter.dev)。页面加载时向它请求一次徽章，该请求本身即 +1。
- **按「设备 × 自然日」去重**：每个浏览器每天只请求一次，当天其余加载直接读本地缓存，所以反复刷新不会把数字刷高。
- 服务不可达时（断网、被墙、服务停摆）自动退回本机计数，并把标签改成「次本机访问」+「统计暂不可达」，不假装那是全网数据。

想彻底关掉：删掉 `assets/app.js` 里的 `COUNTER_URL` 常量与 `initVisitStats()` 调用，页脚那一块自己会退回纯本机口径（或不显示）。

## 七、实现要点

- **雷达图**：手写 SVG，四轴、三层刻度、网格与顶点全部按得分比例算，无图表库。
- **分享卡**：Canvas 2D 现场绘制，1080×1440，含类型色块、四维条形与判定结论。
- **动效**：只做透明度与位移的 `transform` 过渡，滚动进场用 `IntersectionObserver` 一次性触发。
- **路由**：`hashchange` + 视图 `display` 切换，未知路由一律回退首页，不留白屏。
- **容错**：`localStorage` 数据损坏或被禁用时自动重建，不抛错、不阻塞答题。
